# Diplomna Rabota Console
Софтуерен проект към дипломна работа. Приложението е разработено на .NET 10 и е предназначено за сканиране и управление на директории.

## Функционалности
* Скенер за файлова система (File Scanner).
* Визуализация на структурата на папките.
* Интеграция с браузър за преглед на резултатите.

## Технологичен стaк
* **Език:** C#
* **Платформа:** .NET 10 (Windows)
* **IDE:** Visual Studio Code
